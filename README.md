# Hammad Rashid — Portfolio

Hi, I'm Hammad Rashid, a QA Engineer with over three years of experience testing web and mobile applications. This portfolio is a place to share a little about my background, the work I've contributed to, and the tools I use for manual and automated testing.

## Live portfolio

Visit the site: [muhammadhammadrashidofficial.github.io/Portfolio](https://muhammadhammadrashidofficial.github.io/Portfolio/)

## What's on the site

- **About me** — a short introduction and a downloadable copy of my CV.
- **Education and certifications** — my Computer Science degree from the National University of Computer and Emerging Sciences, along with my testing certifications.
- **Services** — the areas I work in, including manual and automation testing, web and mobile testing, functional testing, regression, usability, and performance testing.
- **My work** — a selection of web and mobile projects I've contributed to.
- **Languages, tools, and frameworks** — technologies and testing tools I use, including JavaScript, TypeScript, Python, Cypress, Selenium, Playwright, Postman, and JMeter.
- **Blogs and contact** — links to my writing and ways to get in touch.

## View locally

This is a static site; there is no build step or package installation. Clone or download the repository, then open `index.html` in a browser. If you prefer to run a local server, you can use Python:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Project files

- `index.html` contains the portfolio content and page structure.
- `assets/css/meyawo.css` contains the styles, including the responsive layouts.
- `assets/js/meyawo.js` contains the page interactions.
- `assets/imgs/` contains images used throughout the site.
- `assets/files/resume.pdf` is the CV linked from the About section.

To update the portfolio, edit the relevant content in `index.html` and its styles in `assets/css/meyawo.css`.
